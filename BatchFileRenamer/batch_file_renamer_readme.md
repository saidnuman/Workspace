# BatchFileRenamer

A simple and smart Python script to batch rename any type of files in a specific directory.

## Features

* Batch rename all files (documents, images, videos, etc.) in a folder while preserving their original extensions.

* Customizable base name (e.g., `document`, `project_file`).

* **Smart Zero-Padding:** Automatically calculates the required leading zeros (e.g., `01`, `001`) based on the total number of files, or allows you to manually set the digit count (e.g., `0001`).

## Usage

1. Ensure you have Python installed on your system.

2. Run the script via terminal or command prompt:

   ```
   python batch_file_renamer.py
   
   ```

3. Enter the target folder path when prompted.

4. Enter the new base name for your files.

5. Choose the numbering format (Automatic or Manual).

Done! Your files are now perfectly ordered and easily readable by any operating system.
